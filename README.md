# KTSB

A collection of small, practical, and just-for-fun web tools built by and for the **KTSB** community.

This repository gathers various little apps, toys, and utilities created by KTSB group members. Each tool lives in its own subdirectory and can be developed and deployed independently.

## Projects

| Project | Description | Demo |
| :--- | :--- | :--- |
| [`leg3sb`](./leg3sb) | An interactive clicker with live danmaku (barrage) messages. | [leg3sb.ktsb.org](https://leg3sb.ktsb.org) |
